# 迁移：v14.0 — Profile 加 tagline 选填字段

## 背景

v14.0 引入 `Profile.tagline?: string` 字段 — 一句话身份介绍。展示路径：

- **`/pt-profile` 选择器**：选项拼成 `name — tagline`（一眼分辨 profile 身份）
- **`/pt status`**：新增 `pt tagline:` 行（不受 footer 35 字符截断限制）
- **footer**：`pt: <profile>: <tagline-truncated> <state>`（≤35 字符，超长 → `...` + ellipsis）

## 升级影响

- **无影响**：tagline 选填，旧 Profile 不填照样可加载（back-compat）
- **建议补**：4 个 pt-* profile 已补 tagline（pt-dev / pt-arch / pt-design / pt-devops）
- 建议写法：

  ```yaml
  ---
  name: pt-dev
  blueprint: dev-knowledge
  tagline: Senior dev + QA + Reviewer (3 agents)
  domains: [...]
  ---
  ```

## 修复指南

每个 Profile（按需补）：

1. 打开 Profile（`.pt/assets/profiles/<name>.profile.md`）
2. 在 frontmatter 加 `tagline: <一句话身份介绍>`
3. 建议 ≤ 35 字符（footer 自动裁短，但太短可读性差）

## 例子

| Profile | tagline |
|---|---|
| pt-dev | `Senior dev + QA + Reviewer (3 agents)` |
| pt-arch | `Architect + tech lead (design + pt-devops)` |
| pt-design | `Product owner + architect` |
| pt-devops | `Tech lead + release engineer` |

## back-compat

无 tagline 的 profile：

- `/pt-profile` 选择器显示纯名（无 ` — ` 后缀）
- `pt status` 显示 `pt tagline: (none)`
- footer 显示 `pt: <profile> ok`（不追加 `: <tagline>`）
